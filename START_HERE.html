How to read this page

HS is the Harmonized System of product classification. USLCI is the U.S. Life Cycle Inventory source used here. A row is one recorded product exchange in a documented process—not every product with that name.

A candidate code is a saved proposal, not a recommendation. A mechanical check applies recorded rules; a model assessment is a saved AI finding; an owner decision records this project owner’s limited acceptance. None substitutes for specialist review.
